# Comelit 1.7.20 — inspect HA-managed go2rtc stream state during MSE startup

## Purpose

1.7.20 is diagnostic-only. It does not change Mini App playback behavior.

## Why

The 1.7.19 live capture closed the missing-Opus-producer hypothesis. Even after
mirroring Home Assistant core's Generic Camera producer set, the path remained:

```text
mse_command_received
mse_source_resolved
mse_stream_registered
mse_upstream_ws_open
mse_negotiation_forwarded
<no mse_upstream_reply>
<no mse_upstream_chunk>
mse_fallback at 8001 ms
```

The remaining question is what HA-managed go2rtc actually has inside the stream
after the MSE consumer asks for media.

## New diagnostics

For the active opaque Mini App stream, the integration performs two read-only
`GET /api/streams?src=<opaque_stream>` snapshots:

- approximately 250 ms after `mse_negotiation_forwarded`;
- approximately 4 s after `mse_negotiation_forwarded`.

Each sample emits two log lines.

### Compact counters

```text
COMELIT_MINIAPP_DIAG_GO2RTC
```

Counters include:

- inspection success;
- producer count;
- consumer count;
- whether producer 0/1 is active;
- media counts;
- receiver counts;
- H.264 / PCMA / Opus presence;
- received KB;
- consumer sender count.

### Rich state

```text
COMELIT_MINIAPP_DIAG_GO2RTC_STATE
```

The rich snapshot preserves useful go2rtc state such as:

- connection IDs;
- format names;
- protocols;
- media descriptions;
- codec metadata;
- receiver / sender structures;
- bytes;
- packets;
- drops;
- consumer state.

Network and credential material remains removed before logging:

- source / URL;
- remote address / IP;
- SDP;
- user agent;
- username / password;
- token / cookie / authorization;
- any remaining value matching URL/IP/credential patterns.

The raw go2rtc response is never logged unsanitized.

## Timing

Sampling does not block negotiation. Both snapshots run as separate Home
Assistant tasks after the existing negotiation message has already been
forwarded upstream.

## Unchanged behavior

1.7.20 does not change:

- camera source preparation;
- Generic Camera producer setup;
- MSE codec negotiation;
- MSE timeouts;
- WebRTC fallback;
- HLS fallback;
- Comelit entrance-camera lifecycle;
- Door/Gate paths.

## Live acceptance

After installing 1.7.20 and restarting Home Assistant, open
`camera.parking_6048` once while capturing:

```text
COMELIT_MINIAPP_DIAG
COMELIT_MINIAPP_DIAG_SERVER
COMELIT_MINIAPP_DIAG_GO2RTC
COMELIT_MINIAPP_DIAG_GO2RTC_STATE
```

The 250 ms and 4 s snapshots should show whether the camera producer actually
dialed, which media/codecs it exposed, whether the Opus producer became active,
and whether the MSE consumer acquired senders.

No Door or Gate action is required.
